# MesaFlow

Sistema simples e de baixo custo para pequenos bares e restaurantes.

## Primeira versão

A demo inicial foi personalizada para o **Grão de Mostarda**, usando a identidade visual verde escuro, laranja e creme.

### Recursos atuais

- cardápio digital com visual moderno;
- produtos exibidos com packshots visuais de lata, garrafa, copo e porção;
- Coca-Cola, Coca-Cola Zero, Fruki Guaraná, Fruki Uva, Fruki Laranja, águas, Heineken, drinks, suco e porção;
- pedido pelo QR Code da mesa ou pelo garçom;
- perguntas automáticas por produto, como gelo, limão, copo e açúcar;
- carrinho e envio do pedido;
- tela da copa com Novo → Preparando → Pronto → Entregue;
- cronômetro por pedido;
- chamar garçom e pedir conta;
- estoque básico;
- área administrativa;
- personalização de nome e cor do restaurante;
- funcionamento responsivo em celular, tablet e computador;
- suporte básico a PWA/offline.

## Teste com mesa

Ao publicar o site, abra a página acrescentando `?mesa=8` para simular o QR Code da Mesa 8.

Exemplo:

`https://seu-site.com/?mesa=8`

## Próxima etapa

Conectar um banco de dados em tempo real para que cliente, garçom, copa e administração funcionem sincronizados em aparelhos diferentes. Depois evoluir para multiempresa, permitindo que cada restaurante tenha logo, cores, produtos, preços, mesas e perguntas próprias.
